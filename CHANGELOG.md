# Change Log

All notable changes to the "schematic" extension will be documented in this file.

## [1.1.3] - 2026-10-18

- Fix syntax highlighting for boolean values `true` and `false`.
- Add syntax highlighting for literal `none`.

## [1.1.2] - 2026-10-16

- Update syntax highlighting to match latest language definition.

## [1.1.1] - 2026-10-11

- Add support for sound and image literals.

## [1.1.0] - 2026-10-08

- Add syntax for color and boolean literals.
- Add support for schematic blueprint syntax.
- Fix comments not highlighting correctly inside constraint blocks.
- Remove unused keywords `partial` and `extends`.

## [1.0.0] - 2026-09-01

- Initial release
