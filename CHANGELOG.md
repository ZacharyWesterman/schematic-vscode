# Change Log

All notable changes to the "schematic" extension will be documented in this file.

## [1.1.0] - 2026-10-08

- Add syntax for color and boolean literals.
- Add support for schematic blueprint syntax.
- Fix comments not highlighting correctly inside constraint blocks.
- Remove unused keywords `partial` and `extends`.

## [1.0.0] - 2026-09-01

- Initial release
